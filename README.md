# Winter Arc Tracker

App para llevar el registro diario del Winter Arc de 180 días (1 oct 2026 – 29 mar 2027): hábitos, pasos, comidas, agua, entrenamiento, inglés, antojos vencidos, peso y progreso.

- Sitio estático (HTML + JS, sin dependencias), instalable como app (PWA) y funciona sin conexión.
- Los datos se guardan en el celular (localStorage). Usa **Plan → Copia de seguridad** para descargar o restaurar un `.json`.
- Se publica con GitHub Pages desde la rama `main` (carpeta raíz): cada push actualiza la app.

## Instalar en el celular

Abre la página en el celular y elige **Agregar a pantalla de inicio**: en Safari, desde el botón Compartir; en Chrome, desde el menú ⋮.
